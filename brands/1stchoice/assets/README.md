# 1st Choice assets

Files listed under `assets:` in `../brand.js` are offered in **Add asset** on every tool.
Copy these from `01 Brand/Cans/Cut-outs HD/` on the PC (transparent PNGs, same names):

| File | What |
| --- | --- |
| `classic_can.png` | Classic HD cut-out |
| `classic_can_shadow.png` | Classic with soft ground shadow |
| `passion_can.png` | Passion Fruit HD cut-out |
| `passion_can_shadow.png` | Passion Fruit with soft ground shadow |
| `cans_pair.png` | Both cans side by side (Passion left, Classic right, clear gap) |
| `cans_pair_shadow.png` | Both cans with shadow |

Until a file is here, Studio shows it as "Not added yet". To add a new asset, put the PNG here and add a line to `assets:` in `brand.js`.
No cat mascot stickers unless the owner asks for them.

`prev/` holds a light copy of each file (~1000px WebP, about 100 KB instead of 5–10 MB). Studio shows the light copy first while the HD file loads; saving always uses the HD file. If you replace a PNG here, make a new light copy too (same name, `.webp`, longest side 1000px).
