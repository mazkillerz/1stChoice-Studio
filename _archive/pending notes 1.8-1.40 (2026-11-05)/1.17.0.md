## README lines

In the Board section (after Components / Combine shapes):
- **Flex layout (preview, off by default):** a frame or group can stack its items in a column or a row with a gap, padding (sides / top and bottom), alignment and, for a fixed size, spread (start, centre, end, even). The stack re-flows when anything inside changes (a longer text pushes the rest along, even while typing); a group stack (or a frame set to "fits its contents") grows with what's inside. **Stack** (panel, right-click, Shift+A) puts several picked things in a new stack, guessing direction, order, gap and alignment from how they are placed. Drag inside a stack to reorder; locked things stay put; rows can run right to left. Group stacks can have a box colour and round corners. Turn it on in the Design panel (nothing selected) → Previews, the quick find, or `?flex=1`.

And in the file map line for `lab/`: add `board-flex.js (flex layout preview)`.

## How it is built (for lessons / skill Repo notes)

- `lab/board-flex.js` = `BD.flex`. A stack is just an attribute on a frame or `kind:'group'` group: `flex = {dir:'col'|'row', gap, px, py, align, justify, hug, rtl, w, h, fill, r}`. Saved by the normal `toObj` (all attrs), so undo, versions, .board files, copy/paste and duplicates carry it with no new code. Boards without the attribute are never touched (`reflow()` finds no stacks and returns).
- `BD.flex.reflow()` lays out every stack, innermost first (a nested group's new size moves its parent stack). It runs at the start of `changed()`, after `comps.sync()` in the undo commit, on every keystroke while editing a text, and when web fonts finish loading. Items are measured with `getClientRect({relativeTo:container,skipShadow:true})` and moved by the difference, so rotated, scaled and stroked things all work. Hidden, locked and frame-background (`isBg`) items are left out of the flow.
- Order = layer order (bottom layer first; reversed for right-to-left rows). After a drag (`endMove(list)` → `BD.flex.dropped(list)`) the dropped things take the slot where they were let go.
- Group stacks keep a `flex-bg` rect (not an `obj`, so it is not a layer, not selectable on its own, skipped by `items()`); transparent unless `fill` is set, so the padding is visible to selection and taps. Ungroup and Remove layout delete it.
- Sizes: a group fits its contents by default; resizing it by the handles or typing W/H gives it a fixed box (`w`/`h`) instead of scaling what's inside. A frame keeps its size by default; "Frame fits its contents" makes it hug; resizing a hugging frame by hand turns hugging off.
- Components: a copy takes its main's `flex`; inside stacks x/y and the box size are ignored when comparing a copy with its main, so a copy with longer words re-flows on its own without being rebuilt every step.
- Export needs nothing: the layout only moves real nodes, so PNG 2×, PDF, SVG are the same code paths.
