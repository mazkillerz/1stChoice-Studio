```
type: feature

### Paste on all text
type: feature
After **Copy style**, a new **Paste on all text** button under Paste style puts that look on every line of words in the story in one tap, instead of one text at a time: 2 taps instead of 3 more for every text (buttons and tags keep theirs). One tap of undo brings all of them back.
```

## README lines

Under the tool page's layer bar (More tab), after Copy style / Paste style:
- **Paste on all text**: after Copy style, puts the copied look on every plain text layer in the story at once (one undo step). Buttons and tags are left alone.
- **Text styles**: **Save this style** keeps the selected text's look (colour, font, align, line height, spacing, shadow, background pill, opacity) in a named list on this device (up to 8, auto-named "Style N", renamable from its ⋯ menu, which also has Use on all text and Remove). Tap a style to put it on the selected text or button. Hidden until the first style is saved.

## How it is built (for lessons / skill Repo notes)

- All in `tool()` right after `pasteStyle()`: `allText()` (reg entries `kind==='text' && typ && !empty && !hidden`), `pasteAll(st)` (flush() first so the previous edit stays its own undo step, loads the font once, `pasteStyle` on each, one `render()` → one history commit), `tStyles()` / `setTStyles()` on localStorage `studio:textstyles` = `[{id,name,st,at}]` via `store()` (already try/catch), `paintStyles(id)` (called from `syncInspector()` for text/pill layers; marks the chip whose style equals the layer's current `styleOf()` with `.on` + `aria-pressed`), `styleMenu(tid)` (a `dialog()` with the name input, Use on all text, Remove).
- A style uses the same object as Copy style (`styleOf()`), so a saved style and a copied one behave the same, and old `studio:style` values are untouched.
- Saving the same look twice does not add a duplicate (status says its name); at 8 it says to remove one.
- Kept per device, not per brand (like Copy style). A style with another brand's font falls back to that brand's default font when used.
- CSS: new `.tstyles` / `.ts-*` rules and `#inspPasteAll{flex-basis:100%}` just before the fresh-look block.

## Lessons
