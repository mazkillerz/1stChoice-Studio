## 1. What changed

### 1.1 Stickers and sharp emoji in Board (backlog #26)
- New `lab/board-stickers.js` (`BD.stickers`), loaded after `board.js` in `board.html`. It loads `assets/stickers.js` and `tools/highlight-emoji.js` **only when needed** (Stickers or Emoji assets open, or a board/undo step/paste has a sticker), then calls `window.addEmojiStickers()`. A board without stickers loads neither file.
- A sticker is a `Konva.Shape` `{kind:'sticker', ref:'sticker:<id>', width, height, scol?, label}`: drawn from the sticker's own paths at any size (sharp in the 2× PNG, 2160×3840 for a story), picked by a tap (box hit area). `scol` = its colour; a drawn sticker always has one (default brand ink); an emoji with no `scol` keeps its own colours. The draw function is not saved, so `decorate()` (board.js) calls `BD.stickers.prep(n)` and `loadDoc()` waits for `BD.stickers.need(nodes)`. Same ids as the tool pages (`sticker:star`, `sticker:emoji-heart` …), so never rename one.
- Assets: a new **Stickers** category (14 drawn stickers) next to Emoji. **Emoji** now starts with the 24 sharp emoji (same on every phone, can take one colour), then the old **Keyboard emoji** (text, unchanged) with a one-line note that they use the device's emoji. Asset search finds them by label and id ("heart" finds the Love emoji). Tiles are drawn previews; 4 a row on touch (58px), 5 on a computer.
- Design panel: a **Sticker** / **Emoji** section with one colour swatch (emoji: "Original" = own colours, via No colour). Quick bar: one colour button. W/H fields keep a sticker's shape; the handles keep the ratio (like icons). Replace colour everywhere includes stickers (`scol` in `CKEYS`). Layers list: sticker icon + its name. Duplicate, undo/redo, copy/paste, flip, shadow, opacity, blur work like other layers.
- SVG export: emoji as vector `<path>`s (one path in the picked colour, or each part in its own), drawn stickers as a sharp PNG `<image>` (they are canvas strokes).
- **Fix found on the way:** Board's paste (Ctrl/⌘+V, Paste in the menu) stopped with `n.find is not a function` when the clipboard held a text (or now a sticker): only groups have `find()`. One-line fix in `paste()`; checked by `board-stickers`.
- Engine touches in `board.js` (small): `decorate()` first line, `loadDoc()` waits for sticker files, `bakeScale()` treats `sticker` like rect (width/height), keep-ratio list, `nameOf` label, resize-with-content list.

### 1.2 Text styles shared with the tool pages and Create (backlog #35)
- Board's **Save as style** (Design panel › Text styles) now saves to the same `studio:textstyles` store as the tool pages and Create (`[{id,name,st,at}]`, up to 8, auto-named "Style N", no duplicates, no name prompt any more). The saved styles show as chips in Text styles; tap one = it goes on the chosen text in one undo step; the chip of the look the text has is pressed. Styles saved on a tool page show in Board too.
- `st` uses the tool pages' `styleOf()` shape: `color, font, align, lh, ls, bg, op, shadow`. Board adds `wt` (weight, when not 400) and `bf` (a font only Board has, e.g. Inter/Poppins; then `font` is left out so a tool page keeps its own font instead of a missing one). The tool pages ignore both keys (`pasteStyle` reads only its own keys). Size and position never change.
- Assets › Text: "Text styles" lists the shared ones (tap = put on the chosen text, or add a new text in that look when nothing is chosen; ⋯ = rename or remove, same dialog as the tool pages). A board's **own** styles from before 1.36.0 (`S.styles.text`) stay with that board and still work, under "This board" (Assets › Text and the panel's dropdown). Old boards open unchanged (checked: same data, no sticker files loaded).
- Tap counts: apply a saved style: 2 taps (open dropdown, pick) → 1 (chip). Save a style: 2 + typing (Save, name prompt OK) → 1. Add a sticker on a phone: Layers button, Assets, Stickers, tile = 4 (new).
