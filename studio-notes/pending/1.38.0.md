## 1. What changed

### 1.1 Highlight covers, Product type: Size and Position (backlog #10)
- Two new per-cover fields, shown only when Cover type = Product, placed **above** the product list (the list has 16 tiles, so controls under it were out of sight):
  - `psize`: range **Size**, 60–130 %, step 5, default **100** (label shows "Size 100%").
  - `ppos`: seg **Position**: Higher / Middle / Lower (`up` / `mid` / `down`), default **mid**; `HL_POS = {up:-140, mid:0, down:140}` px from the circle's middle.
- Drawing: `bw = min(620, 740·ratio) · psize/100`, centre y = `960 + HL_POS[ppos]`. At the defaults `k = 1`, `dy = 0`: the exact same numbers as before. **Old covers pixel-identical**: old drafts / saved designs have no `psize` / `ppos`; `applyRecipe` fills them from `newPage()` defaults, and `draw()` also falls back (`||100`, `||0`). Proved in `highlight-product.mjs` by an md5 of the canvas drawn by the pre-1.38 `highlight.js` (from git history) vs now (same hash; a 105 % default makes it fail).
- Per cover (not global), like the product pick. The layer can still be dragged / pinched on top of this (the layer transform applies after).
- Tap count: bigger can = Style, drag Size (1 drag); move it = Style, Higher/Lower (2 taps, often 1 with the sheet open).
