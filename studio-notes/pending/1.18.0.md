## How it works (for the notes / README)
- New `assets/render.js` (`StudioRender`): each picked design is opened in a hidden same-origin frame of its own tool page, `tools/<tool>.html?design=<id>&render=1`. With `render=1`, `tool()` exposes `Studio.renderer` (`ok`, `missing`, `pages`, `W`, `H`, `page(pg,max)`), which draws with **`renderPage()`**, the function `save()` now uses too (moved out of `save()` unchanged), with the same 2× → 1.5× → 1× steps down. So the batch PNGs are byte-for-byte the files you get by opening the design and tapping Save (the test proves it for a Restock, a Photo story and a 4-slide Carousel post).
- The select-bar button is created in `home()` (before Delete), so `index.html` is not touched.
- Phone: one `navigator.share` with every file; if the drawing took too long for the phone's tap window, the dialog offers **Save to Photos** (same rule as Save). Computer: one ZIP via `assets/batch.js` (`<brand>-pictures-YYYYMMDD-HHMM.zip`), a single picture downloads as a PNG.
- Low memory: same message as Save, but says "device" on a computer.
