## What's New cards (changelog format)

```
### Flip
type: feature
Need the arrow to point the other way? Tap a sticker, shape, can or picture, open **Move** and tap **Flip**: it turns into its mirror image, left to right, without going upside down (Rotate used to turn a curved arrow on its head). Tap **Flip** again to put it back. It's kept in the saved design, Undo takes it back, and the full-size save comes out flipped too. Words never flip: the button doesn't show for text, buttons or the logo.
![before](assets/whatsnew/1.14.0-flip-before.jpg)
![after](assets/whatsnew/1.14.0-flip-after.jpg)

### Emoji highlight covers
type: feature
Highlight covers have a new cover type: **Emoji**. Open **Style**, tap **Emoji** and pick one of 24 (a pin, a chat bubble, a star, a heart, coffee, ice, a gift, a price tag, a truck, a cart, a clock, a calendar, sparkles, a bolt, the sun, the moon, a yummy face, a thumbs up, a crown, a camera, a note, fire, a box and a question mark). It sits big in the middle of the circle on your cover's background, with the same Circle / Ring / Nothing behind it as the rest of the set. Each new cover starts with a different one. Emoji are drawn, not typed, so they're sharp in the save and look the same on every phone. In **Colour** you can turn one into a single brand colour; it moves, sizes and flips like any layer.
![before](assets/whatsnew/1.14.0-emoji-before.jpg)
![after](assets/whatsnew/1.14.0-emoji-after.jpg)
```

## README lines

- Tool page, layer bar → **Move**: nudge, Centre / Middle, Rotate (±15°, Straight) and **Flip** (mirror left to right; stickers, shapes, cans and pictures only, never words or the logo).
- Highlight covers: cover types Icon, Word, Photo, Product and **Emoji** (24 brand-neutral emoji drawn as vectors; graphics from Twemoji by Twitter, Inc. and contributors, CC-BY 4.0; credit in `tools/highlight-emoji.js`).

## How it is built (for lessons / skill Repo notes)

- Flip is `S.layers[id].flip=true` (absent = not flipped), so old designs draw exactly as before and undo / drafts / the recipe / Duplicate get it for free. `layer()` applies it as `ctx.scale(k*-1,k)` after rotate, i.e. mirrored in the layer's own frame (a flipped, turned arrow still turns the way the slider says). Hit box and selection outline don't change (they are symmetric).
- `canFlip(b)` (module scope in studio.js) decides from the reg entry: kinds `asset`, `sticker`, `shape` only, and not `noFlip`. `h.asset()` sets `noFlip` for tinted assets (the logo) and for any brand asset with `noFlip:true`. `layer()` checks the same rule while drawing, so a recipe with `flip` on a text layer still draws the words the right way.
- Copy / Paste style does not carry flip (it's geometry like size and rotation, not a look).
- Emoji: `tools/highlight-emoji.js` holds 24 Twemoji converted to `[fill, path d, opacity?]` lists in a 36×36 box (circles/ellipses turned into arc paths at build time). `hlEmoji()` draws them with cached `Path2D`s: no image loading, sharp at 2160×3840, identical on iPhone and Android. Grid tiles use the same paths as inline SVG. A layer colour draws a one-colour silhouette. **Never rename an emoji id: saved designs point to it.**
- Emoji is a new `kind` option and a new `emoji` field with `pageDefault` by page index; old designs have no `emoji` value and get the default, which they don't use unless kind is emoji.
