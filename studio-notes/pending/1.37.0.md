## 1. What changed

### 1.1 Save pictures in Continue editing covers Create drafts (backlog #42)
- `tools/create.js`: a `?render=1` mode (`RENDER`). `startRender(draft,design)` opens the draft (`BD.openStored`) or a saved Create design (`openDesign`), then sets `S.id=null` and `st.ready=false`, so the editor can never write a draft, a board or a thumbnail from the hidden frame (`touch()` also returns in render mode). No templates sheet, no toasts, URL kept.
- It exposes the same hook as tool pages: `Studio.renderer={ok,missing,pages,W,H,page(pg,max)}`. `page()` waits for fonts, then calls Create's own `BD.exportFrame(frame,{scale:2,type:'image/png'})`: the same code as the Save sheet, 2× lossless PNG, stepping down to 1.5× / 1× only when memory runs out (`max` from the batch is respected). **Pixel-identical** to Create's own Save (checked in the suite).
- `ok:false` for a draft that is gone and for a team template; `missing` = a photo no longer on this device (draft) or a team photo that did not download (design), so render.js says "has a photo missing" instead of saving a picture with a hole.
- `home()` (Continue editing): Create drafts are no longer skipped (`skip` only for videos; a draft record with neither `json` nor `board` says "could not be opened"). The tidy-up offer (1.32.0) now includes saved Create drafts too.
- Bonus: **Saved → Save pictures** on a saved Create design used to wait 30 s and say "could not be opened" (Create had no renderer); it now saves it like any other design.

### 1.2 Create's Recently used row shows team templates (backlog #46)
- The row is drawn at once with the brand templates (as before); once `paintTeam` has the team list, `paintRecent()` redraws it in the true order of `studio:tplRecent:<brand>` (`'t:'` and `'team:'` ids), newest 3, skipping templates that are gone, keeping the thumbnails already drawn. Team cards show the team thumbnail and name (`dir="auto"`); a tap applies the team template like the Team templates list (`applyTeam`, so it moves to first).
- When the brand part is empty, a hidden `#crRecentAt` marker holds the place and the row is added once team templates load, so "only team ids" shows the row once loaded; signed out = brand ones only, never an empty row. Search hides the row; clearing shows it only if it has cards.
- No layout change: the same `.cr-rec` card and row; no new CSS.
