## What changed
1. **New place "Save the frame only" is really see-through (1.29.0 finding).** `renderPage()` sets a module flag `framePass` while it draws a frame-only PNG; `makeHelpers()` then swaps `h.photo` / `h.backdrop` for no-ops. `photoAspect` still reads the photo, so the window is exactly the size it is in the story. The normal Save and Save pictures are untouched (`framePass` is false there; set and cleared in a `try/finally`). The link now sits right under "Only save to the team" (the empty status line between them made a bigger gap).
2. **Tool descriptions fit one line.** Every `TOOLS` blurb was cut with "…" in All tools on a phone (11 of 11 at 390px; 3 on Home). Now 0 at 360 and 390. The words taken out moved into `keys`, so search still finds them (checked: flavours, scattered, headline, product, 1080, place name).
3. **All tools sheet shorter and quieter:** one intro line ("Tap a star to pin a tool to your home on this phone/device": it said "phone" on a computer too), no "Pin more tools…" hint when only one tool is pinned (the line above says it; the drag hint still shows for 2+), and **Done is the quiet grey button** like every tool sheet since 1.15.0 (it was the blue accent). Same for **Settings → Done**.
4. **Saved design menu lines up:** its row icons were 18–24px wide, so the labels started at four different places (70–76px). All icons are one 20px size now (`.act-row svg`), labels on one line. Also tidies every other `.act-row` menu (collections, Peek actions).
5. **`/` on a computer** jumps into search: Home → the Studio search, Saved → its own search opens and takes the typing. Ignored while typing in a box or with a pop-up open. The magnifier's tooltip says "(/)".
6. Tests/tools: `backgrounds.mjs` gives the Grain-after-reload check a longer settle and one retry (1.29.0 flake); `tapscan.mjs` honours `BASE`.
