## What changed
1. **Carousel: This slide comes first in Style.** Slide type, Two photos (Stacked / Side by side) and Words place now sit at the top of the Style sheet under "This slide"; White / Cream / Black and the rest follow under "All slides". Changing one slide's type no longer needs a scroll past ~900 px of settings that apply to every slide. Engine: a style field with `lead:true` is drawn in a `[data-fields="lead"]` box above the styles (only when a tool has one; no other tool changes). **Highlight covers too** (after 1.38.0 landed, with the lead's OK): This cover (Cover type, Size/Position for Product, Product, Icon, Emoji, Word, Small word) now comes first, All covers below. Picking each cover's icon was below ~700 px of settings for all covers. Draw code untouched; highlight 17/0, highlight-emoji 40/0, highlight-product 63/0 (incl. its pixel-identity checks).
2. **Collage: Border colour waits for a border.** At Border 0px the colour palette did nothing, so it is hidden until the slider leaves 0, and shows while the slider moves (not only on release). The picked colour is kept when the border goes back to 0. Engine: `when:{field, not:[…]}` (hide for these values), and fields that depend on a slider update while it moves.
3. **`tests/contrast.mjs`** takes its URL from argv, then `BASE`, then :8080, so `run.mjs` runs it on the session's port (1.39.0's report).
4. **A check for a rejected thing that had none:** `simplify40` fails if a tool row in All tools carries a "New" label (taste.md "Things he rejected", dropped 22 Oct).
