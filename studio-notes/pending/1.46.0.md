## Bugs fixed
1. **Offline with a kept sign-in said "Not on the team yet. Ask the owner to add this email"** on Home and Saved. `isMember()` returned false when the check itself failed. Now `home()` uses the new `checkMember()` (throws on a network error) and shows **"You're offline"** + Try again.
2. **A slow cloud left Home's Saved row and the Saved page blank forever** (the account check hung; no skeleton, no message). Now: a skeleton at once, **"Still loading…"** + Try again after 8 s, and requests that hang are stopped (cloud.js `timedFetch`: 20 s for the database and sign-in, 90 s for storage reads; photo uploads have no limit).
3. **An old sign-in with no signal: blank for 45 s+** (supabase-js `getSession()` keeps retrying the refresh). `sessionState()` stops waiting after 12 s and the page says so. When the phone reports offline (`navigator.onLine` false) the note shows at once, and the `online` event loads again with no tap.
4. **Home at 360 px scrolled sideways by 3 px while the button says "Sign in"** (the top bar was too wide). One rule in studio.css: a little less padding on the Account button under 375 px.
5. **The chosen collection's ⋯ slid under the row's end fade** (backlog 1.5.0 note, confirmed): the chip grows during its open animation after the row was scrolled; the keep-in-view step now runs again once it has grown. At 360 and 390, first / middle / last / long Arabic collection.
6. **Delete collection with no signal: the dialog sat there with no word** (an uncaught error). It now says "No connection. Check your internet and try again." and Delete can be tapped again. The owner's team list in Account says the same instead of staying empty; saved thumbnails fail quietly offline (no console error).
7. **Cloud errors read as code** ("Saved designs: TypeError: Failed to fetch", "Upload: Failed to fetch"). `fail()` in cloud.js turns any network error into "No connection. Check your internet and try again." (or "The connection is too slow right now. Try again in a moment."), marked `err.offline`. This also improves the tool Save sheet's team-save message and the sign-in dialog with no signal, without touching `tool()`.
8. A list already on screen stays when a refresh fails (after a rename, say); a toast says "You're offline. These are your designs from before."

## Improvement
**All tools: drag edge auto-scroll** (backlog 1.5.0). With many pinned tools the sheet scrolls; holding a dragged row near the sheet's top or bottom edge now scrolls it, so a tool can go from first to last in one drag. A short drag works as before.

- Lessons: supabase-js `getSession()` with an expired access token and no network does not return for 45 s+ (refresh retries); never await it bare on a screen that shows something. `isMember()` returning false on error made "offline" look like "not on the team": an error must never read as a "no".
- Lessons: a keep-in-view scroll measured right after `innerHTML` is wrong when the element animates its width; measure again after the animation (450 ms).
- Test tip: Playwright's `ctx.setOffline(true)` also blocks the local server (page reloads fail); to test offline UI, route the cloud host to `abort('internetdisconnected')` and fake `navigator.onLine` with `Object.defineProperty(Navigator.prototype,'onLine',…)` (see `hub-offline.mjs`).
