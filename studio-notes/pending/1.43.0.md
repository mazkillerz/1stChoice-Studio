## Bugs fixed
1. **Save sheet hid the preview on short phones.** On a 375×667 iPhone SE and a 360×740 Android the Save sheet (`max-height:min(76dvh,640px)`) left ~40–55px above it, `fit()` still gave the preview its 120px minimum, so the preview slid up under the top bar (Carousel/Highlight: its top at −20…−30px, under the strip too). Now the Save sheet's height is capped so ~100px of preview stays (`calc(100dvh - top bar - bottom bar - 112px)`; no change at 390×844), the preview's minimum is 72px, and on paged tools the slide strip steps aside while a sheet leaves no room for it (`.stage.tight`, set by `fit()`; back when the sheet closes). The Save button stays in view.
2. **Two Add photo buttons on a computer** (1.40.0 audit finding). The Photo card's tile and the blue "Add your photo" under the preview showed at once; the blue one was also a third filled button and sat below the fold. On a computer only the tile shows now (`.stage>.cta-photo` hidden at ≥ 821px); phones keep the blue button (the only one they see without opening Photo).
3. **More tab too tall on a phone** (backlog 1.19.0 note, sessions brief). At 360px Copy style / Save this style / Paste style wrapped to 2–3 lines in three columns, and saved text styles wrapped onto extra rows (up to 4 rows with 8 styles), so the preview shrank to 115×205. Now the style buttons sit two to a row on one line (Copy · Save this style before anything is copied; after Copy: Copy · Paste style / Save this style · Paste on all text, via CSS `order`; a lone Copy style fills the row) and saved styles are one row that scrolls sideways, like the Save sheet's collections. Preview with everything showing at 360×740: 155×275 (was 115×205). Desktop unchanged.
